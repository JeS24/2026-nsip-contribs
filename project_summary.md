# iWatchRoad

## Summary

- A mobile application built with Flutter that detects road conditions and potholes in real-time.
- Utilizes on-device machine learning via ONNX models and device camera/sensors.
- Integrates geolocation mapping and communicates with a FastAPI backend for data tracking.
