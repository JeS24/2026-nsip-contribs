# Project Tirtha — Platform UX

## Summary

- Project Tirtha is an open-source web GIS platform for mapping and visualizing cultural heritage sites across India using interactive 3D models and geographic data.
- Designed and implemented a 3-column interface (dynamic sidebar | 3D model viewer | interactive map) inspired by Google Maps, replacing the previous single-panel layout.
- Built a context-aware sidebar that displays live site details, geo-coordinates, Google Maps links, and contributor statistics when a heritage site marker is clicked on the map.
